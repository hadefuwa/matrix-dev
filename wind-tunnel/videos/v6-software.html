Wind Tunnel Software

Data acquisition and logging from the wind tunnel's touch-screen controller. How readings are displayed, how to capture many data points efficiently, and how to export them for analysis.

Key takeaways

01 · Live readouts

The touch-screen shows pressure, velocity and (with the two-force module) lift and drag, all updated continuously.

02 · Sensor zero

Zeroing is always done from this screen, with the fan off. Re-zero between holders.

03 · Many readings, fast

For high-volume experiments like WS3 (23 tappings) the screen-based approach is fine — but plan a recording sheet so you don't lose track.

04 · Export to spreadsheet

Readings copy cleanly into Excel / Google Sheets for graphing. Learners should set up a template before they start a long sweep.

Where this fits

Use this video in Week 5 (Lift Generation Mechanics) ahead of Worksheet 3 — when learners face 23 tappings × 3 angles of attack = 69 readings to capture cleanly. Software literacy pays back the time it takes to watch.
