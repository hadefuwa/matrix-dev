How to Set Up the Wind Tunnel

Powering on the unit, navigating the touch-screen controller, zeroing sensors and reaching the default operating state — the standard sequence learners follow at the start of every lab.

Key takeaways

01 · Power-on sequence

Mains switch → controller boot → fan idle. The fan does not spin until a speed is selected on the touch-screen.

02 · Touch-screen controls

Fan-speed up / down in 10% steps, sensor zero buttons, pressure and velocity readouts on one screen.

03 · Always zero with fan OFF

Before any reading, with the fan idle, press the zero button so that the digital sensors read 0 at ambient pressure.

04 · LED airflow indicator

The animated LEDs on the side run faster as the fan speeds up — a quick visual sanity check that everything's working.

Where this fits

Use this video in Week 2 (Fluid Dynamics & Continuity) right after assembly, before learners go anywhere near an experiment holder. Every lab from Week 3 onwards opens with the same set-up sequence.
